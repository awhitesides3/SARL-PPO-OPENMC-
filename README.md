# Surrogate-Assisted Reinforcement Learning (SARL) applied towards the coupling of Proximal Policy Optimization (PPO) and Open Monte Carlo (OPENMC)

This code couples PPO and OpenMC via a surrogate-assisted RL algorithm. 

## Overview

This code is applied towards optimization in the field of nuclear design, specifically radiaiton shielding design. The preliminary application is towards the thermal shielding of the Nuclear Ship Savannah (NSS).

This research is presented in the 2026 ANS Annual Conference under the title "Surrogate-assisted Reinforcement Learning for Radiation Shielding Design" - https://www.ans.org/meetings/ac2026/session/view-3760/#paper_11823
