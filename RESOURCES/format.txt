2-Layer Model Sensitivity Study for the Surrogate Approach

Data File Naming Convention:
[doseConstraint][penaltyType][penaltyNormalization][penaltyScalingFactor][NPS][#MCRuns].npz

Input Variables:
1. doseConstraint: float-type, ex. 0.5. 
2. penaltyType: binary-type; 0=soft constraint and 1=hard constraint.
3. penaltyNormalization: binary-type; 0=no and 1=yes.
4. penaltyScalingFactor: int-type; ex. 1e1, 1e2, etc...
5. NPS: integer-type; ex. 1e2, 1e4, etc...
6. #MCRuns: int-type, ex. 1, 100, etc...

Surrogate Results File Naming Convention:
[#timesteps][iterations] + 'Data File Naming Convention' + .txt

1. #timesteps: number of timesteps for each RL process: int-type, ex. 1e2, 1e3, etc...
2. iterations: number of iterations of RL processes: int-type, ex. 1e2, 1e3, etc...
notes:
-Ensure that the dose_c variable and penalty definition are the same in both the surrogate.py and run_surrogate.py scripts
